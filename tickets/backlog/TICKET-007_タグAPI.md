## 概要

タグの作成・一覧・リネーム・削除 API を実装する。Firestore の `/tags/{tagId}`。

## 背景・目的

ノートを横断するテーマ分類。CISSPのドメイン（1〜8）とは無関係な軸であり、
旧実装ではタグ側にドメイン属性を持たせてタグ一覧が埋まる問題があったため、
**ドメインはノートの列、タグは純粋な横断テーマ**として分離する。

## 受け入れ条件

- [ ] `api/openapi.yaml` にタグのパスとスキーマが定義され、生成物がコミットされている
- [ ] タグの作成・一覧・リネーム・削除ができる
- [ ] タグは `{ id, name, color }` のみを持つ（**ドメイン属性を持たない**）
- [ ] 同名タグの重複作成が 400 で拒否される
- [ ] タグ削除時、そのタグを参照しているノートの `tags[]` から取り除かれる
- [ ] `name` の空文字・超長文字列が 400 で拒否される
- [ ] ユースケース層のユニットテストがある
- [ ] Firestore リポジトリの統合テストがある
