## 概要

React Router のルーティング、Firebase Auth の Google サインイン画面、
ID トークンを自動付与する API クライアント、TanStack Query の設定、
アプリ全体のシェル（ナビゲーション・テーマ切替）を実装する。

## 背景・目的

以降のすべての画面がこの土台の上に乗る。特に「ID トークンの付与」と
「Firestore SDK を使わない」という2点を最初に固定しないと、後から直すのが高くつく。

## 受け入れ条件

- [ ] Google サインインでログインでき、サインアウトできる
- [ ] 未ログイン時は全画面がサインイン画面にリダイレクトされる
- [ ] **API クライアントが全リクエストに `Authorization: Bearer <IDトークン>` を自動付与する**
- [ ] トークン期限切れ時に自動更新され、それでも 401 ならサインイン画面に戻る
- [ ] 403（許可メール外）のときに「利用が許可されていない」旨の日本語メッセージを表示する
- [ ] **`src/api/` の生成済み型を使い、レスポンス型を手書きしていない**
- [ ] **`frontend/` 内で Firestore SDK（`getFirestore` 等）を使っていない**
- [ ] TanStack Query の QueryClient が設定され、エラーハンドリングの共通方針がある
- [ ] ライト / ダークのテーマ切替が動き、選択が保持される
- [ ] モバイル幅（375px）でナビゲーションが破綻せず、タップ領域が44px以上ある
- [ ] `make lint` と `make test-front` が通る
