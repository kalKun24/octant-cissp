## 概要

Firebase Auth の ID トークンを検証する認証ミドルウェアを実装し、許可メールのホワイトリストで
アクセスを絞る。あわせて `make dev` に Firestore / Auth の両エミュレータを組み込む。

## 背景・目的

このプロジェクトの防壁は「ID トークンの検証」「許可メールの照合」「uid による個人データ分離」の
3つだけで、すべてこのチケットで作るミドルウェアに集約される。
また、Auth エミュレータが無いとローカルでも CI でも認証付き API を検証できない。

## 受け入れ条件

- [ ] 認証ミドルウェアが Firebase Admin SDK で ID トークンを検証し、`uid` と `email` を context に入れる
- [ ] `email_verified == false` のトークンを 401 で拒否する
- [ ] 環境変数 `ALLOWED_EMAILS`（カンマ区切り）に含まれないメールを **403** で拒否する
- [ ] トークン無し・壊れたトークン・期限切れトークンを **401** で拒否する
- [ ] `/health` 以外のすべてのエンドポイントが認証ミドルウェアを通る
- [ ] `make dev` が Firestore エミュレータ（8808）と **Firebase Auth エミュレータ（9099）** を起動する
- [ ] Auth エミュレータの `accounts:signUp` で取得した ID トークンで API を呼べることを統合テストで確認している
- [ ] **認証をスキップする環境変数・分岐が実装されていない**
- [ ] context から `uid` を取り出すヘルパが `contextkey` 経由で提供されている
- [ ] ログにトークン・メールアドレスが出力されない
