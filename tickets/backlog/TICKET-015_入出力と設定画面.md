## 概要

全データの JSON エクスポート / インポートと、設定画面（表示設定・出題設定・
進捗リセット）を実装する。v1 の仕上げ。

## 背景・目的

データの持ち出し手段があることは、単一のクラウドサービスに依存しないための保険。
旧実装からの手動移行の受け口にもなる（自動移行はしない方針のため、
**旧データを取り込む唯一の経路がこれ**）。

## 受け入れ条件

- [ ] 全ノート・タグ・進捗・プロンプトを JSON でエクスポートできる
- [ ] エクスポートした JSON をインポートして復元できる
- [ ] **インポート時にスキーマを検証し、不正な JSON は 400 で拒否する**（部分適用しない）
- [ ] インポート前に「何件が追加・更新されるか」を提示して確認を取る
- [ ] エクスポートはブラウザ直接ダウンロード（Cloud Storage を経由しない）
- [ ] 設定画面で出題設定（既定の範囲・出題順・問題数）を保存できる
- [ ] 設定が `/users/{uid}` に保存され、再ログイン後も保持される
- [ ] 進捗リセット・全データリセットができ、**実行前に確認が出る**
- [ ] リセットは自分のデータのみに作用し、他ユーザーの個人データに影響しない
- [ ] エクスポートした JSON にトークン・APIキーが含まれない
- [ ] モバイル幅（375px）で設定画面が操作できる
