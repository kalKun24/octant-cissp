## 概要

学習状況の可視化。CISSPドメイン1〜8ごとの習熟度リング、連続学習日数、
日別のヒートマップ、復習期限の件数を API と画面の両方で実装する。

## 背景・目的

継続のための動機づけ。**復習期限のノートに最短で到達する導線**をここに置くことで、
毎日の学習開始点になる画面にする。

## 受け入れ条件

- [ ] ドメイン1〜8ごとの習熟度（正答率・演習回数）を返す API がある
- [ ] 日別集計（`/users/{uid}/days/`）から連続学習日数とヒートマップ用データを返す API がある
- [ ] 復習期限を迎えたノートの件数を返す
- [ ] **統計の集計で全ノート・全進捗を無制限に読み込まない**（日別集計を利用する）
- [ ] ドメインごとのリングが SVG で描画される
- [ ] ヒートマップが直近の学習日を表示する
- [ ] 連続学習日数が表示される
- [ ] **復習期限の件数から、その場でドリルを開始できる**
- [ ] ライト / ダークの両テーマでリング・ヒートマップの色が識別できる
      （WCAG AA のコントラスト比を満たす）
- [ ] モバイル幅（375px）でリングとヒートマップが破綻しない
- [ ] ユースケース層のユニットテストがある
