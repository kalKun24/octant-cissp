## 概要

ノートの一覧・詳細・編集画面を実装する。Markdown 描画（コードハイライト・mermaid図）、
`[[wikiリンク]]`、バックリンク表示、検索・絞り込み、タグ付けを含む。

## 背景・目的

アプリの主画面。長文の可読性とモバイルでの編集しやすさが体験を決める。
Markdown の描画は XSS の主要な攻撃面でもあるため、サニタイズの経路をここで確定させる。

## 受け入れ条件

- [ ] ノート一覧が表示され、`type`（問題 / 知識）とタグで絞り込める
- [ ] 一覧がカーソルページネーションで追加読み込みされる（全件を一度に取得しない）
- [ ] タイトル・本文でのテキスト検索ができる
- [ ] ノート詳細で Markdown が描画され、**コードハイライトと mermaid 図が表示される**
- [ ] **`[[ノートタイトル]]` が該当ノートへのリンクになる**
- [ ] **バックリンク（そのノートを参照している他のノート）が一覧表示される**
- [ ] ノートの新規作成・編集・削除ができ、削除前に確認が出る
- [ ] 問題ノートの編集時のみドメイン（1〜8）と4択・正解・解説の入力欄が出る
- [ ] **Markdown の描画が `marked` → `DOMPurify` → `dangerouslySetInnerHTML` の順**になっている
- [ ] **DOMPurify を通さない HTML を `dangerouslySetInnerHTML` に渡していない**
- [ ] `<script>` や `javascript:` を含むノートを保存・表示してもスクリプトが実行されない
- [ ] モバイル幅（375px）で編集画面が操作でき、タップ領域が44px以上ある
- [ ] ライト / ダークの両テーマで Markdown・コードブロック・mermaid が読める
