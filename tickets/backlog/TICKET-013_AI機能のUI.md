## 概要

AI による解説生成・タグ提案・問題生成の UI と、プロンプトテンプレートの編集画面を実装する。

## 背景・目的

AI 応答は同期 REST のため 10〜30 秒待つことがある。
**待ち時間の見せ方**と、生成結果を採用する前に確認できることが体験の要になる。

## 受け入れ条件

- [ ] ノート編集画面から解説生成・タグ提案を実行できる
- [ ] 問題生成を実行し、生成された問題ノートを確認してから保存できる
- [ ] **生成中であることが明示され、10〜30 秒の待ちでも操作不能に見えない**
- [ ] 生成結果をプレビューし、**採用 / 破棄 / 再生成**を選べる
- [ ] エラー時（429 レート制限 / 502 生成失敗 / ネットワーク断）に、
      **何が起きたかと次にどうするか**を日本語で表示する
- [ ] 429 のとき `Retry-After` の値をもとに再試行可能になるまでの目安を示す
- [ ] 設定画面でプロンプトテンプレートを編集・保存でき、変更履歴を閲覧できる
- [ ] 過去のリビジョンへロールバックできる
- [ ] 生成中に画面を離脱しても不整合が起きない
- [ ] モバイル幅（375px）で操作でき、タップ領域が44px以上ある

## サブチケット（コミット計画）
