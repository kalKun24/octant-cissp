## 概要

4択フラッシュカードでの演習画面を実装する。出題設定・解答・正誤表示と解説・
自己評価による採点・セッション結果のサマリまで。

## 背景・目的

日々の学習の主導線。**モバイルでの片手連続タップ**が主要シナリオであり、
1問あたりの操作数を最小にすることが体験を決める。

## 受け入れ条件

- [ ] 出題設定（範囲: 全件 / 復習期限のみ / タグ絞り込み、出題順、問題数）を選んで開始できる
- [ ] 4択が表示され、選択すると正誤と解説が表示される
- [ ] 解説の Markdown が正しく描画される（TICKET-009 のコンポーネントを再利用する）
- [ ] 自己評価（SM-2 の quality）を選ぶと次の問題に進む
- [ ] セッション終了時に結果サマリ（正答率・所要時間・間違えた問題の一覧）が出る
- [ ] 結果から間違えた問題のノートへ遷移できる
- [ ] 「もう一度」「終了」が選べる
- [ ] **モバイル幅（375px）で、選択肢が親指の届く範囲に配置され、タップ領域が44px以上**
- [ ] 解答の記録がサーバに反映され、リロードしても進捗が失われない
- [ ] 出題対象が 0 件のときに、次にどうすればよいかを示すメッセージが出る
- [ ] `prefers-reduced-motion` 有効時にアニメーションが抑制される
